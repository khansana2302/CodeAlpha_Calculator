# CalcSpace — Calculator
CodeAlpha Frontend Development task.

## Technologies
HTML5, CSS3 and JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Percentage, clear and delete controls
- Live display and result
- Keyboard support: numbers, operators, Enter, Backspace and Escape
- Light/dark theme toggle
- Division-by-zero handling

## Run
Open index.html in a modern browser.

Suggested repository: `CodeAlpha_Calculator`
